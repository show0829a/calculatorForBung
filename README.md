# ⚡ 벙비 계산기 (Bung Calculator)

> 모임 총무를 위한 차수별 모임 정산 & 실시간 입금 확인 웹 애플리케이션

## ✨ 주요 기능
- **차수별 지출 및 참석자 자동 상속**: 1차, 2차, 3차 차수별 금액과 참석자를 유연하게 관리하고 동일 참석 패턴별로 자동 그룹화
- **공백/쉼표 실시간 감지**: 긴 이름 텍스트를 복사-붙여넣기 시 즉시 개별 참석자 칩으로 자동 등록
- **카카오톡 정산 텍스트 원클릭 복사**: 단톡방 공유용 투명하고 정돈된 정산 메시지 생성
- **실시간 입금 확인 관리 (체크리스트)**: 멤버별 입금 완료 여부 원터치 토글 및 미입금자 독촉 텍스트 복사
- **카톡 정산 텍스트 스마트 불러오기**: 다른 봇이나 메모장에서 이미 계산된 정산 텍스트를 붙여넣으면 차수, 금액, 인원, 계좌를 자동 인식
- **이전 정산 내역 보관함**: 지난 모임 정산 스냅샷 저장 및 보관함 내 개별 입금 현황 관리
- **100% 브라우저 기반 & 무과금**: 백엔드 서버 없이 브라우저 `localStorage`로 안전하게 영구 보존

## 🚀 기술 스택
- HTML5, Modern CSS (Flexbox & Grid, CSS Variables)
- Vanilla JavaScript (Zero Dependencies)
- Pretendard & Inter Web Fonts
